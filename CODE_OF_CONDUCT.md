# Code of conduct

We want this project to be a practical and respectful place to collaborate.

## Expected behavior

- Be clear, patient, and constructive.
- Critique code and decisions, not people.
- Respect different experience levels and communication styles.
- Keep issues and pull requests focused on the project.
- Protect private information in logs, screenshots, and examples.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language
- Publishing another person's private information
- Deliberately disruptive or deceptive contributions
- Repeated off-topic promotion or spam

Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when necessary.

Report conduct concerns privately to the project maintainers through the repository's available private contact method.
