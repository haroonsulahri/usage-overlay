# App logos

The detail card shows a badge for each app. Add official logos here to use them
instead of the built-in generic badges:

| File | App |
| --- | --- |
| `codex.png` | Codex (OpenAI) |
| `claude.png` | Claude (Anthropic) |
| `cursor.png` | Cursor (Anysphere) |

Use square PNGs, at least 64×64 pixels, with transparent or rounded corners.
Rebuild after adding or changing a file. Any file left out keeps its generic badge.

The logos are trademarks of their owners. Check each brand's guidelines before
redistributing them, for example in a public release.
