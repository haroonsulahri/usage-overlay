# App logos

Codex and Cursor use unmodified official assets bundled with their Windows apps:

- `codex.png`: `webview/assets/codex-app-ga-logo-3e5209898ca3.png` from OpenAI Codex 26.1013.4894.0 (`app/resources/app.asar`).
- `cursor.png`: `resources/app/resources/win32/code_150x150.png` from the installed Cursor Windows application.

These PNG files are embedded as WPF resources, so the badges also work in single-file releases. Claude retains its existing badge. The logos identify the supported applications; Usage Overlay is independent and is not endorsed by their owners. Trademarks belong to OpenAI and Anysphere respectively.
